# Student Management System

## About the Project
A Python-based Student Management System that allows users to manage student records through a simple, menu-driven interface.

## Features
- Add new student records
- View all student records
- Search for a student using their ID
- Update student details
- Delete student records
- Validate student IDs and marks
- Handle invalid input

## Technologies Used
- Python
- Lists and Dictionaries
- Functions
- Conditional Statements
- Loops
- Exception Handling

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

## How to Use
Run the program and select an option from the menu:

1. Add Student
2. View Students
3. Search Student
4. Update Student
5. Delete Student
6. Exit
